## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Mutation that never applied | Twice this phase a mutation check "passed" because `ruff format` had rewrapped the target lines, so the text substitution matched nothing. Green means nothing if the mutation is not in the file. | blocking | Print the exact removed/changed block to stdout before running the suite; assert the file's hash changed. |
| Fixture that cannot exercise the property | A tie-order test drew `etime`s so finely that 4,000 rows shared 3 values — with no ties, both merge orders are the same stream, so the test was green forever for an unrelated reason. | blocking | Measure the property's density in the fixture (here: rows per distinct `etime`, real day = 2.71) and assert it before asserting the behaviour. |
| Invariance property green on a stub | A constant-returning feature passes both shuffle-invariance properties — a constant genuinely cannot see the future. | blocking | Every invariance assertion needs an anti-vacuity counterpart that fails when the feature stops responding to its inputs. |
| Test package shadowing the real one | Creating `mvp/tests/<pkg>/__init__.py` where `mvp/<pkg>/` also exists shadows the real package on `sys.path`. Bit this project four times across Phases 2 and 4. | blocking | Never add `__init__.py` under `mvp/tests/` for a name that exists at `mvp/`; match `tests/spec`, `tests/tools`, `tests/tracking`. |
| Static scanner treated as the guarantee | Three review rounds each closed the reviewer's exact bypass spelling and the next reviewer found another. Detection of "every way to write x10^6" does not converge. | advisory | Name the runtime/data invariant that carries the guarantee and red-prove it first; add static coverage on top, never instead. |
| Bare `python3` importing the numba kernel | Writes `.nbc`/`.nbi` into `mvp/features/__pycache__/`, which fails `test_no_numba_cache_artifacts_under_mvp` on the next run. | advisory | Set `NUMBA_CACHE_DIR` outside the repo for any ad-hoc script; pytest already pins it via conftest. |

| Pushed branch -> CI trigger | Any push to any branch (including a scratch red-proof branch) triggers a real CI run and consumes Actions minutes |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-2-12 | Elevation of Privilege | .github/workflows/ci.yml | mitigate | Top-level `permissions: contents: read` — the workflow has no write scope to the repo, no ability to push tags/releases/packages; this phase's CI needs only checkout + read-only checks |
| T-2-13 | Tampering | .github/workflows/ci.yml (third-party actions) | mitigate | `astral-sh/setup-uv` pinned to the exact tag `v10.1.0` (not a floating major-version ref like `@v10` alone resolving to a mutable branch, and not `@main`) — standard supply-chain hygiene for a workflow with no other secrets to protect |

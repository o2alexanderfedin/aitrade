## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Developer-authored source files -> AST/regex scanners | The scanners trust that source parses as valid Python; a syntactically-broken file is caught by other tooling (ruff/pytest collection), not these scripts |
| mvp/uv.lock on disk -> check_pin_versions.py | Trusts the lockfile as the record of what's actually installed; a manually `pip install`-ed package outside the lock is invisible to this check |

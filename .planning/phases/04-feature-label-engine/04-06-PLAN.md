| Boundary | Description |
|----------|-------------|
| catalogue declaration -> implementation | A declared information set is a promise; unparsed, it is unverifiable prose |
| leakage property -> the thing it tests | An invariance-only suite passes against a constant; the test suite itself is a trust boundary |
| pre-commit -> CI | The two callers must run the same text, or a gate exists in one place only |

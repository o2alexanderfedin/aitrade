From `mvp/data/ingest/trade_side.py`: `SIGN_MAKER_IS_SELLER = +1` (aggressor bought). `ofi`'s positive direction must match it -- both features carry the same sign convention, so a model never has to learn that two "buy pressure" columns disagree about which way is up.

The CKS formulation, verbatim from 04-RESEARCH-NOTES.md Q1 (arXiv:1011.6402 Section 2.1, cross-checked numerically against the QuestDB SQL form over all 17,167,290 real quote rows of 2026-09-13, max abs diff 2.84e-14):
```
e_n =  I{b_n >= b_{n-1}} * qb_n  -  I{b_n <= b_{n-1}} * qb_{n-1}
     - I{a_n <= a_{n-1}} * qa_n  +  I{a_n >= a_{n-1}} * qa_{n-1}
```
Four INDEPENDENT indicators, never an elif chain: at an unchanged price both indicators on that side fire and the size-delta case falls out, so a repeated identical quote is exactly 0.0 with no branch to test.

Ring-buffer sketch that compiles under `@njit(cache=True)` on numba 0.65.1, and the `while rb_t[head] <= t0` line that makes the window half-open `(t-1s, t]`: 04-RESEARCH-NOTES.md Q3 "Minimal working sketch". The state contract (write it as the module's first docstring section -- later plans and the simulator conform to THIS):

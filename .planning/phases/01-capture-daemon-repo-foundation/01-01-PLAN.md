## Phase Goal

> ROADMAP.md's Phase 1 `**Goal:**` line is not in `As a / I want to / so that` user-story format

Irreplaceable Binance USD-M perpetual-futures L1 + trade history is being recorded reliably from
day 1, inside a contained `mvp/` repo skeleton whose environment is locked by a uv lockfile
honoring the numba/numpy/llvmlite pin.

<objective>
Stand up the `mvp/` repo skeleton, lock the canonical capture schema and its dtypes (a Phase 3/4
contract that is expensive to change later), and prove the entire capture stack end-to-end
against the REAL live Binance exchange — one connection, one bookTicker row, one trade row, one
Parquet file, read back and verified. This is the Walking Skeleton (WALKING_SKELETON=true):
everything after this plan (continuous operation, redundancy, hardening) layers onto a slice
that already works end to end against real traffic, not a mock.

Purpose: capture uptime is the single schedule-critical deliverable in this project (Binance L1
history is not backfillable) — this plan proves the stack works before any further time is spent,
and freezes the row schema before Phase 3/4 come to depend on it.
Output: `mvp/` scaffold with pinned env, `mvp/data/schema.py`, `mvp/data/capture/{config,streams,parse,seq}.py`,
a passing unit test suite, `mvp/scripts/verify_live_connection.py`, and `SKELETON.md`.
</objective>

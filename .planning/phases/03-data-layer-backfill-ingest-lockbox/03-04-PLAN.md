**Check (1)'s cause-family rule, decided here:** only rows whose `cause` starts with `"merged-silent"` (covering both the reactive `"merged-silent:"` and the proactive `"merged-silent-ongoing:"` variants) count as real coverage loss -- both connections were down, which is the only condition Phase 1's redundant-socket design cannot absorb. `"connection-silent"`/`"connection-silent-ongoing"` rows are excluded (redundancy absorbed the loss); `"__disk__"`/`"__power__"` rows are excluded (not outages, informational alarms); `"trade-id-skip"` is excluded from check (1) specifically (it feeds a different, per-message-loss signal that check (3)'s NA-rate and the archive/capture reconciliation already cover indirectly -- including it here would double-count against merged-silent's own coverage figure for the same underlying event when both fire together).

**Ongoing/reactive dedup rule, decided here:** the watchdog's `merged-silent-ongoing` row and rotation.py's eventual `merged-silent` reactive closing row for the SAME outage share the exact same `gap_start_rtime` (both read `last_seen_state["merged"]`, which is not mutated again until a real frame arrives), and the watchdog fires **at most once** per outage (it latches `_active_stall["merged"] = True` after the first firing and does not re-fire on subsequent ticks). Therefore: group ledger rows by `(gap_start_rtime,)` among cause-family rows, and within each group take the row with the MAXIMUM `gap_end_rtime` -- this collapses a watchdog's partial-duration row and the eventual full-duration reactive row (if both exist for the same outage) into one canonical interval, without needing to parse the `cause` string beyond the family-prefix check above.

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Gap ledger (capture-authored) -> DQ report -> loader pause | The loader's refusal to serve degraded data is only as trustworthy as the chain producing the dq_status it reads |
| Git-committed acknowledgement -> training pipeline | An acknowledgement is a human (or agent) claim that a known-bad day is safe to use anyway; it must be reviewable in a diff, never silent |

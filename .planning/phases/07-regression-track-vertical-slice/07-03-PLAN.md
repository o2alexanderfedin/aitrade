The module docstring carries the four design constraints, because they are what stops Phase 8 editing this file:
(1) `fit` takes ONE `FitInputs`, never an `(X_train, y_train, X_eval, y_eval)` quadruple — LightGBM's early stopping is a trainer's private business, carved out of the rows it was given; a sklearn trainer that will never early-stop is not made to carry two dead parameters forever.
(2) `FitInputs` names a cached PARQUET PATH plus column names, never materialised arrays — 44,249,548 rows at 101 bytes is 4.5 GiB, so "just pass the arrays" is not neutral at this scale. A sklearn trainer calls `.to_numpy()`; a torch trainer streams row groups.
(3) `epochs` / `batch_size` / `device` / `n_estimators` are HYPERPARAMETERS, not protocol parameters: they already flow through `hyperparameters`, which is also exactly what `predictor_id` hashes.
(4) `predict` takes ALREADY-NORMALISED features and returns the TARGET's unit (a 10s return, D-07-10). Normalisation is resolved from a manifest (D-07-11) and is identical for every model class; putting it inside `predict` would duplicate it four times and force the numpy-only re-evaluation test to import the normalisation loader.
State explicitly: **no sklearn type appears in any annotation in this file**, and the words `epochs`, `batch`, `early_stopping`, `device` appear in no signature.

**The rule is about SIGNATURES, not about the file's text**, and the distinction is load-bearing: the docstring above must SAY the words `sklearn`, `epochs` and `early_stopping` in order to state the constraint, and `predictor_from_artifact` dispatches on `model_class` values that are literally `"sklearn.Ridge"` and friends. A naive `'sklearn' not in inspect.getsource(...)` check would forbid the very documentation and the very registry the design requires. Enforce it with `ast` instead, scanning ONLY parameter names and annotation text, exempting docstrings and string constants. The repo already has the exemption helper twice — copy `mvp/tools/check_latest_ban.py:56`'s `_docstring_nodes(tree)` (the same helper appears at `check_lockbox_containment.py:314`) and skip any Constant whose `id()` is in that set.
